IT Support Cost Optimization

📌 Project Description

This project is concerned with the analysis of IT support tickets that can help cut down operational expenses as well as increase customer satisfaction levels. For this purpose, the data analysis was conducted using such tools as Python.

🎯 Goals

20% reduction in support expenses

Customer satisfaction increase

Prevention of ticket escalation where possible

Identification of expensive issues categories


🛠️ Technologies Utilized

Python

Pandas

NumPy

Matplotlib

Seaborn

Jupyter Notebook


🔍 Key Findings

Ticket categories analysis

Duration of resolution analysis

Patterns of ticket escalation

Insights for cost optimization

Customer satisfaction trends


📈 Result

Based on the data analysis results, certain recommendations were made to enhance support operations and minimize costs.
